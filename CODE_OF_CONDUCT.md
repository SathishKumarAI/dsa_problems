# Code of conduct

## The short version

Be decent. Assume good faith. Critique the work, never the person.

## What this project expects

**Disagree with evidence.** This repo's whole standard is that claims get measured rather than
asserted, and that applies to disagreements too. "This is wrong" is not useful; "this measures
1,999,000 comparisons where the page says linear, here is the script" is. The same courtesy runs
the other way: if someone measures your work and it does not hold up, that is the process working,
not an attack.

**Be specific about scope.** Reviewing a pull request means reviewing what it set out to do. A PR
that says what it deliberately did *not* do has earned the right not to be asked for it.

**Nobody is expected to know the conventions before reading them.** A first contribution that
misses the ratchet, forgets `npm run docs:learn`, or files in the wrong document is a normal first
contribution. Point at the file that explains it and move on.

**Credit what you build on.** If a measurement, a phrasing or a counterexample came from someone
else's issue, say so in the commit body.

## Not acceptable

Harassment, discriminatory language, personal attacks, deliberate intimidation, sustained
disruption, or publishing anyone's private information. Sexualised language or imagery is not
appropriate anywhere in this project.

This applies in issues, pull requests, commit messages, code comments and any other project space.

## Reporting

Raise it with the maintainer — [@SathishKumarAI](https://github.com/SathishKumarAI) — by opening a
private report through GitHub, or by contacting them directly. Reports are handled confidentially.

The maintainer may edit, hide or delete contributions that violate this document, and may block
accounts for repeated or serious violations. Where a response is not obvious, the bias is toward
explaining first and enforcing second — except for harassment, where it is not.

## Scope

This document covers project spaces, and public spaces when someone is representing the project.
